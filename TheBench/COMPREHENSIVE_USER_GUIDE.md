# Sports Scores Application - Complete User Guide

## Getting Started

### Installation & Setup
1. **Download** the latest release from the GitHub releases page
2. **Extract** the files to your preferred location
3. **Run** `main.py` or use the provided executable
4. **First Launch** - The app opens to the main sports selection screen

### Navigation Basics
- **Tab/Shift+Tab**: Move between UI elements
- **Arrow Keys**: Navigate within lists and tables
- **Enter/Space**: Activate buttons and selections
- **Alt+B**: Back navigation (available throughout the app)
- **Escape**: Close dialogs and return to previous screens

## Core Features Overview

### Live Scores Hub - Your Command Center
**Purpose**: Real-time monitoring of games across all sports
- **Access**: Select "Live Scores" from the main menu
- **What You Get**: All currently active games from every supported sport
- **Pro Tip**: Keep this view open during game days - it's your central dashboard
- **Monitoring**: Press Alt+M on any game to get notifications for score changes

**Best Practices**:
- Open Live Scores first thing on game days
- Use it as your home base - monitor multiple sports simultaneously  
- Perfect for weekend afternoons when multiple games are happening
- Switch between this and specific games without losing your place

### Team Schedules & Season Navigation
**Purpose**: Deep dive into any team's complete season
- **Access**: Choose sport → Select team from the list
- **Navigate**: Use Previous/Next Day (Alt+P/Alt+N) or week navigation for football
- **Season View**: See the entire season at a glance with W/L indicators
- **Game Details**: Enter on any game for complete information

**Power User Features**:
- **Export Functionality**: Export any team's schedule to keep offline records
- **Historical Navigation**: View past games with full details and statistics
- **Future Planning**: See upcoming games with broadcast information

### Game Details - The Information Hub
**Purpose**: Everything you need to know about any specific game

#### Available Information Tabs:
- **Box Score**: Complete statistical breakdown
- **Plays**: Play-by-play action (when available)
- **Leaders**: Top performers and key statistics
- **Standings**: Current league/division standings
- **Injuries**: Player injury reports and status
- **News**: Game-related articles and stories
- **Broadcasts**: TV, radio, and streaming information

**Navigation**: Tab through available sections, Enter to select

### Standings & League Overview
**Purpose**: Complete league standings and divisional breakdowns

#### Two View Modes:
- **Basic View**: Essential standings (W, L, PCT, GB, Streak)
- **Expanded View**: Comprehensive stats including playoff odds, run differential, etc.

**Multi-Division Navigation**:
- Use Ctrl+Tab/Ctrl+Shift+Tab to switch between divisions
- Each division displayed in separate, easy-to-navigate tables
- Perfect for understanding playoff races and division standings

## Sport-Specific Power Features

### Baseball (MLB) - Rich Statistical Experience

#### Pitch-by-Pitch Audio
**Game Changer Feature**: Listen to individual pitches with audio descriptions
- **Access**: Open any game → Plays tab → Navigate to specific pitches
- **Usage**: Select any pitch, press Alt+P to hear audio description
- **What You Get**: Ball/strike calls, pitch type, velocity, location
- **Perfect For**: Understanding the flow and key moments of games

#### Advanced Statistics
- **Player Leaders**: Batting averages, home runs, ERA, strikeouts
- **Team Statistics**: Comprehensive team performance metrics
- **Historical Data**: Season-long trends and comparisons

### Football (NFL/College) - Weekly Navigation Excellence

#### Weekly Game Organization
- **Current Week Focus**: App automatically shows current week's games
- **Easy Navigation**: Previous Week (Alt+P) / Next Week (Alt+N)
- **Season Overview**: Navigate through entire season week by week

#### Export Logs - Hidden Gem Feature
**Highly Recommended**: The export log feature is outstanding for football
- **Use Case**: Keep track of game results, scores, and key information
- **Access**: Available from team schedule views
- **Value**: Perfect for fantasy football, following specific teams, or season analysis
- **Format**: Clean, organized data you can reference later

### Basketball (NBA) - Fast-Paced Information
- **Live Score Updates**: Real-time scoring during games
- **Player Statistics**: Points, rebounds, assists, shooting percentages
- **Team Performance**: Advanced metrics and efficiency ratings

### Hockey (NHL) - Complete Game Coverage
- **Period-by-Period**: Detailed scoring breakdown
- **Player Statistics**: Goals, assists, saves, penalties
- **Goaltender Performance**: Save percentages and shutout tracking
