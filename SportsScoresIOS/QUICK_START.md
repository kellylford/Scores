# 🚀 Quick Start Guide - Sports Scores iOS

## Open the Project
1. Open **Xcode** (install from Mac App Store if needed)
2. Open: `/Users/kellyford/Documents/Scores/SportsScoresIOS/SportsScores.xcodeproj`

## One-Time Setup
1. **Xcode → Settings → Accounts** → Add your Apple ID
2. Select project → **Signing & Capabilities**
3. ✅ Check "Automatically manage signing"
4. Change Bundle ID to: `com.YOURNAME.sportsscores`

## Run on iPhone
1. Connect iPhone with USB cable
2. Trust computer on iPhone (enter passcode)
3. Select iPhone from device menu in Xcode (top bar)
4. Click ▶️ Play button

## Enable on iPhone (First Time)
1. **Settings → Privacy & Security → Developer Mode** → ON
2. Restart iPhone
3. After build: **Settings → General → VPN & Device Management**
4. Trust your Apple ID
5. Launch app from home screen

## That's It! 🎉

The app will show:
- Sport selection screen
- Live scores for each sport
- Standings with 3 view modes
- Game details (box scores, plays, leaders)

## View Modes
Toggle between views using the segmented control at top of standings:
- 📊 **Table View**: Grid format
- 📋 **Quick List**: Comma-separated
- 📖 **Full List**: Header-value pairs

## Troubleshooting
- **Build error?** Clean: Product → Clean Build Folder (⌘⇧K)
- **Untrusted?** Settings → General → Device Management → Trust
- **Can't connect?** Unlock iPhone, try different cable

Need more help? See full README.md in the project folder.
