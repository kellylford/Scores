## What's New in Version 0.8.0

### Feature Parity with iOS
The Windows app is now at feature parity with the iOS version of Scores. The navigation and user experience differ between platforms, but the same information is available in both apps. The one exception is stadium touch tours, which remain iOS-only for now.

### World Cup Hub
The 2026 FIFA World Cup and 2027 FIFA Women's World Cup each have a dedicated hub with four tabs — Scores, Group Standings, Bracket, and News. Use Alt+P and Alt+N to move between match days on the Scores tab. Group standings support all three table view formats (Table, Quick List, Full List).

### Golf
PGA Tour and LPGA Tour now have a dedicated hub showing the current tournament leaderboard and the full season schedule.

### NFL Draft
Browse NFL Draft picks by year and round from the home screen.

### Favorite Teams
Add teams to your favorites from any sport using the Team Hub button (Alt+H). Favorite teams appear as cards on the home screen with quick links to their schedule, roster, and news.

### Live Scores — All Sports
The Live Scores view now includes completed games for the day alongside in-progress and scheduled games.

### User Guide
A User Guide is now bundled with the app and accessible from the home screen. It opens in your default browser.

### Bug Fixes
- Transactions were showing "no data available" for all sports — fixed.
- Weather was not displaying in game details — fixed.
- NFL schedule navigation no longer crashes during the off-season.
